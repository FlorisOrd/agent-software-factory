# Factory delivery team

For software setup, implementation, maintenance, testing or review in this
repository, read and use [factory-delivery](.agents/skills/factory-delivery/SKILL.md)
before planning or changing files. The main agent is the lead; implementation and
independent checking require different native agents. Do not substitute role names
in one conversation for delegation.

The Factory itself is the current product. The supplied brief and acceptance
criteria are in [ASF-MVP-01](docs/ASF-MVP-01.md). Preserve existing work and stay in
this repository. Apply the owner's current request and authorization boundaries.

Record which repository instructions and skill the session loaded, together with
available native session/task identifiers. If a required capability is unavailable,
report its specific failure and the unmet criterion rather than simulating it.

For restoration or resumption of this preserved state, read RESUME.md before acting; historical approval and experiment stop rules still apply.
